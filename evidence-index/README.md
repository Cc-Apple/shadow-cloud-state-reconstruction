# Evidence Index

This folder contains public evidence indexes and manifests for the Shadow Cloud state-reconstruction package.

## Included material

- Source root audit
- Source file inventory
- Source keyword evidence
- Source status summary
- Final score components
- Final verdict table
- Source adoption register
- Guardrails
- Falsification shortlist
- Key source copy manifest
- SHA256 manifests
- Skipped-large-file manifest

## Raw artifact boundary

Raw artifacts are not included in this public repository. Excluded material includes:

- raw iOS logs
- sysdiagnose archives
- iMazing backup artifacts
- Manifest.db generations
- private screenshots/videos
- Apple ID values
- BSSID raw values
- banking / OTP records
- large internal CSVs

Large or sensitive artifacts are represented by SHA256, file size, and source-path references where appropriate.

## Non-claims

This index does not prove:

- attacker identity
- state attribution
- Apple attribution
- C2 endpoint
- connection success
- hidden MDM enrollment
- explicit usageClientId old→new transition
- complete clean control
